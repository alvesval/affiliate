# AIAffiliateIntelligence v1.15 RC3.6 — Pinterest Professional Copy

## Alterações
- Copy específica para Pinterest, evitando repetir o título completo na descrição.
- CTA alinhado ao botão nativo “Acessar o site”; a URL deixa de ser repetida no texto do Pin.
- Disclosure publicitário mantido e escrito de forma mais natural.
- Texto evita inventar desconto, benefício ou característica não disponível no cadastro do produto.
- Novo botão “Recriar texto” na variação da campanha para atualizar campanhas já existentes sem recriar a campanha, mídia ou referências visuais.
- O publisher continua usando `variant.caption` como descrição tanto no Sandbox (Image Pin) quanto no Standard (Video Pin).
