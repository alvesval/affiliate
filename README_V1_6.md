## Observação sobre Cloudflare Pages
Este projeto Next.js também contém páginas dinâmicas do workspace. Para o deploy público completo, prefira o fluxo Next.js suportado atualmente pela Cloudflare (Workers/OpenNext) ou publique somente a camada institucional como conteúdo estático. Verifique a documentação atual da Cloudflare antes do deploy, pois o suporte muda com o tempo.
